Git Push Guidelines

A friendly checklist for pushing changes to GitHub (PowerShell).

1. Quick checks

cd 'C:\Users\vyasa\My Files\Homepage'
git status
git branch --show-current
git log --oneline -n 5

2. Stage & commit

git add -A
git commit -m "Short, meaningful message"

3. Sync remote & rebase (recommended)

git pull --rebase origin main
git push origin main

If you encounter conflicts: fix them, git add, then git rebase --continue.

4. New branch workflow

git checkout -b feature/short-name
# work, commit...
git push -u origin feature/short-name

5. If push is rejected

Fetch + rebase as above, or inspect diffs:

git fetch origin
git log --oneline HEAD..origin/main   # remote-only commits
git log --oneline origin/main..HEAD   # local-only commits

6. Force push (use with caution)

git push --force-with-lease origin main

Tip: Use SSH for easier auth, or store a PAT for HTTPS. For help, paste errors here and I’ll guide you.
